# English Academy A&B: Landing Page

A responsive landing page for an English language school, built as a freelance project.

**Live demo:** https://english-academy-a-and-b.netlify.app

## Overview

A one-page website that presents the school, its courses and how to get started, with a clear call to action for new students. Designed to be fast, clean and easy to use on mobile devices.

## Features

- Responsive layout for desktop, tablet and mobile
- Contact form: visitors leave their contact details, and the school owner receives them by email
- Clear sections presenting the school and its courses
- Deployed on Netlify

## Tech stack

- HTML5
- CSS / SCSS
- JavaScript
- Netlify (hosting and deployment)

## My role

Frontend development, responsive layout, contact form integration and deployment.

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/YurchykD/english-school-ab-landing-page.git
   ```
2. Open `index.html` in your browser.

The contact form delivers email only on the deployed site.
